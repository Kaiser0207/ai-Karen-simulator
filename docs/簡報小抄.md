## 🔒 死背(數字 / 真值表)
- **成功** = 奧客 LLM `ended=true`(**不是血條歸零**)
- **失敗** = 怒值 ≥ **100** · **超時** = 回合用盡 · 三者都進評審
- 怒值變化 **夾 ±30**(防作弊)
- SER 4 類順序:**Angry / Happy / Neutral / Anxious**
- SER 架構:**CRAB 多模態** · 音訊 **XLS-R-300M** · 文字 **XLM-R-large** · **LoRA r16/a32**
- 資料:**MSP-Podcast** 8→4 類 · batch16 · ~8 epoch · AMP+grad-ckpt
- 指標:**WAR / UAR / macro-F1**(類別不平衡 → 看 UAR/F1)
- 長句切段:>12s 觸發 · **句末標點 > 子句標點≥25% > 等時平衡**
- 微服務:`urllib` POST **/predict_pcm**(base64 PCM)

## ⚡ 必答 Q&A(三句頂住)
- **和解誰判?** → 奧客 AI 當下判(ended),評審只打分,不決勝負。
- **中文準嗎?** → 目前英文訓練、靠多語編碼器遷移,會掉;**雙語重訓中**(MSP+EmotionTalk,train 2.5:1,LoRA)。
- **詞級時間戳幹嘛?** → 長句依時間戳切段、各段 SER、依段長加權,輸出逐段 timeline。
- **為何拆微服務?** → 主專案與 SER 的 **PyTorch 版本衝突**,各 venv + HTTP 隔離。
- **Gemini vs Groq?** → Gemini 好但易 **429**;Groq 快穩。抽象層可切。
