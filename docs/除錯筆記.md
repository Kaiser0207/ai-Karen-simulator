# 除錯筆記 — Kaiser0207

> 我在後續開發踩到的問題與解法,與朋友的 [`開發錯誤紀錄.md`](開發錯誤紀錄.md) 區隔。

## Gradio 6.0:`theme` / `css` 要在 `launch()` 傳,不是 `Blocks()`
- **症狀**:`gr.Blocks(theme=..., css=...)` 完全沒生效,只噴一行 UserWarning。
- **原因**:Gradio 6.0 把 `theme`/`css` 從 `Blocks` 建構子搬到 `launch()`。放 `Blocks()` 會被忽略
  (連朋友原本的 `css=CUSTOM_CSS` 在 Gradio 6 上也一直默默失效)。
- **解法**:`demo.launch(..., theme=THEME, css=CSS)`。

## `pkill -f "python app.py"` 會把自己殺掉
- **症狀**:指令異常結束(exit 143 / 144)。
- **原因**:`pkill -f` 比對整條命令列,連「正在執行 pkill 的那行 bash」本身(字串內含 `python app.py`)也被一起殺。
- **解法**:改用 PID:`kill $(ss -ltnp | grep ':<PORT>' | grep -oP 'pid=\K[0-9]+' | head -1)`。

## 前景等待被環境中止(exit 144)
- **症狀**:`sleep`、`curl --retry-delay` 在前景被中止。
- **解法**:用 `curl --retry N --retry-connrefused`(伺服器一啟動就返回,不會空等),或改零等待檢查。

## 從本機(Windows)連不到遠端 server
- **症狀**:瀏覽器開 `127.0.0.1:<PORT>` 顯示 ERR_CONNECTION_REFUSED;app 其實跑在遠端 fcu-server3。
- 進一步:從本機 `ssh` 遠端的 port 22 timeout(校園防火牆對外擋)。
- **解法**:用 **VS Code 的 PORTS 面板** Forward 該埠,再開 `http://127.0.0.1:<PORT>`(VS Code Remote-SSH 自帶轉發)。

## `git push` 回 403(明明讀得到)
- **症狀**:已存憑證能讀(`GET /user`、讀 public repo 都 OK),一 `push` 就 403「Permission denied」。
- **原因**:已存的是**唯讀 / 未涵蓋此 repo 的 fine-grained token**。
- **解法**:`gh auth login`(瀏覽器 OAuth 取得有寫入權的 token),push 時用 gh 的憑證 helper:
  `git -c credential.helper= -c credential.helper='!gh auth git-credential' push ...`。

## commit 作者不是我的 GitHub 帳號
- **症狀**:GitHub 顯示作者是別的帳號(用錯 email),我沒被算成 contributor。
- **解法**:`git config user.email "<id>+<login>@users.noreply.github.com"`;舊 commit 用
  `git filter-branch --env-filter ... -- --all` 改寫作者,再 `git push --force`。

## AKARU 選關卡縮放一直「卡卡的 / 突然放大縮小」
- **症狀**:用「手風琴」依距離改 `width`,放大縮小頓挫;改純平移又做不到「3 細條 + 焦點長到 60%」。
- **原因**:① 直接改 panel 寬會讓裡面的視覺/文字**跟著重排(reflow)**,每幀重算文字排版 → 卡。
  ② 純平移是固定寬,沒有縮放,無法同時呈現休息態三細條與焦點 60%。
- **解法**:**裁切式 slice**——外框只動 `flex-basis` 並 `overflow:hidden`,內層固定 `60vw`(=焦點寬)。
  變寬只是「露出更多同一張內容」,內層尺寸不變、不重排 → 縮放滑順。焦點用浮點 `curF`(滾輪累加 ÷ STEP,
  再 lerp)驅動,`fracFor(索引−curF)` 連續給寬度;大名等外框長到 >40% 才淡入。
